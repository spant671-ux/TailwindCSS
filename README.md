# TailwindCSS

A React app built with Vite. The app lives in [`01Tailwind`](./01Tailwind) and is currently a minimal starter with Google Fonts configured for Inter, Poppins, and Space Mono; Inter is applied globally.

## Getting started

```bash
cd 01Tailwind
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint
